# 浏览器扩展（Chrome / Edge，MV3）

把**当前页面渲染后的完整 DOM** 发给自托管的 个人bookmark。

## 为什么需要它

服务端抓取对两类站点无能为力：

| 站点 | 服务端 | 扩展 |
|---|---|---|
| 小红书 | ❌ 正文和图片由带签名的 API 加载，HTML 里只有空壳 | ✅ 读渲染后的 DOM |
| 抖音 | ⚠️ 只有 meta 级 | ✅ |
| 公众号（受限文章） | ⚠️ 可能被拦 | ✅ 用你已登录的会话 |
| 普通网页 | ✅ | ✅ |

扩展不碰你的账号密码：它只读你已经打开的页面，不模拟登录、不碰请求签名。

## 安装（开发者模式，约 30 秒）

1. Chrome 打开 `chrome://extensions`
2. 右上角打开 **开发者模式**
3. 点 **加载已解压的扩展程序**，选择本目录 `apps/extension`
4. 工具栏出现图标（可固定到顶栏）

Edge 同理：`edge://extensions`。

## 配置

点扩展图标，填两项：

| 字段 | 填什么 |
|---|---|
| 服务器地址 | 浏览器能访问到的地址，**含端口**，例如 `http://192.168.1.10:3081` |
| 访问令牌 | 服务器的「设置 → 访问令牌」里新建的 `pb_...` |

填完点「测试」，显示「连接正常」即可。

> 第一次保存时会弹一个权限请求，问是否允许访问你的服务器地址——
> 这是 `optional_host_permissions` 的设计：不装扩展就要"访问所有网站"。

## 用法

打开任意文章/笔记页 → 点扩展图标 → **保存当前页面**。

「发送渲染后的整页 HTML」默认勾选，**别关**。关了只发链接，小红书/抖音就只剩 meta 信息。

保存后后台异步抓取，几秒后回列表查看。

## 已知限制

- 只在**桌面** Chrome/Edge 可用，不支持手机浏览器（iOS 没有 MV3 扩展）
- 页面必须在**已登录**状态下打开，否则拿到的还是空壳
- `chrome://`、扩展页、PDF 内置阅读器等无法注入
- 整页 HTML 上限 4MB（服务端限制），超大会返回 413
